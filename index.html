☁️ GitHub Sync Setup

1
Go to your GitHub repo → click Add file → Create new file → name it collection.json → paste {} as the content → click Commit changes
2
Go to github.com/settings/tokens/new (also found under Settings → Developer settings → Personal access tokens → Tokens (classic))
3
Give it any name (e.g. pokebinder), set expiration to No expiration, tick the repo checkbox, scroll down and click Generate token
4
Copy the token immediately — GitHub only shows it once. Paste it below along with your GitHub username and repo name.
⚠️ Your token is stored only in your browser's localStorage — it never leaves your device except to talk directly to GitHub's API.
GitHub Username Repository name File path in repo Personal Access Token
